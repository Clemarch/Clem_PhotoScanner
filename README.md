# Photo Triage

Application pour iPhone qui aide à trier les photos d'une journée : elle les regroupe en paquets,
repère les meilleures et montre lesquelles supprimer à la main. Tout se passe sur l'iPhone :
aucune photo n'est envoyée, aucune photo n'est supprimée par l'app.
